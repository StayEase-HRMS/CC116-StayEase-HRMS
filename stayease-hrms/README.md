# EaseStay Hotel Reservation & Management System

Repository for the EaseStay HRMS.

### How to set up

1. Clone the repository, either through VSCode's UI, or through your system's terminal/command prompt
```
$ git clone https://github.com/StayEase-HRMS/CC116-StayEase-HRMS.git

```

2. In the VSCode built-in terminal, enter these commands at the root directory of your local repo. 
```
$ npm install
$ npm install tailwindcss @tailwindcss/vite

```
3. Run the system.
```
$ npm run dev

```
